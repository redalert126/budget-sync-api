# Mobile client (Day 3)

Delete this README, then run `npx create-expo-app@latest mobile` from the repo root (it expects an empty folder).

Scope: one screen listing transactions from the deployed API. Time-box it to two hours; this project's focus is the backend.
Put the API base URL and a sandbox user's token in `app.config.js` `extra`, never in source control for a real user.
